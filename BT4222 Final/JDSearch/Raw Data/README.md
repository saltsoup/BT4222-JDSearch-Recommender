# Data Sources

### The project's data sources are the JDSearch data set. These files are between 0.9GB and 5GB in size, and cannot be easily uploaded to Github with free accounts. 
To download the data, please contact the project owners, or the authors of: https://arxiv.org/pdf/1905.06874, whose dataset we reference.

One data source can be found here:https://github.com/rucliujn/JDsearch
